# Rest Countries App

Mobilna aplikacija izrađena u sklopu kolegija Razvoj mobilnih aplikacija.

Aplikacija koristi REST Countries API za dohvat podataka o državama.

## Funkcionalnosti

- dohvat država putem REST API-ja
- prikaz naziva, regije i zastave države
- pregled detalja odabrane države
- prikaz glavnog grada, populacije i koda države
- povratak s detaljnog prikaza na listu

## Tehnologije

- Kotlin
- Jetpack Compose
- Retrofit
- Gson
- Coil
- REST Countries API
